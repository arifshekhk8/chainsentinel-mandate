# Published competition references

2026 Shenzhen International FinTech Competition · International Track · Topic F: Agent Wallet.

The printed deadline is 20 October 2026, 23:59 Beijing (21:59 Bangladesh). English is the submission language. The rulebook lists technical documentation, presentation within 10 minutes, demo video within 5 minutes, source/README, security self-assessment and execution evidence. The current website marks video required while the printed PDF marks it optional; the submitted package includes it.

Topic F requests on-chain transaction hashes. This prototype explicitly labels Ethereum Sepolia and test tokens; organizer acceptance of testnet evidence is not independently established. Registration/identity material is not part of this source repository.
